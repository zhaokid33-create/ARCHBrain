## 1. 巨构建筑 Megastructure Architecture

### 核心概念
Reyner Banham《巨构：近代的城市未来》（1976）定义：
- 框架性：大型框架，较小单元可"插入"或"挂接"其上
- 永久性与可变性并存：主框架稳定，内部单元可替换
- 城市尺度：巨构本身即构成一座城市或城市片段
- 基础设施整合：交通、市政、公共空间高度融合

Fumihiko Maki（槇文彦）1964年《集合形式研究》：将巨构定义为"集合形式"的一种类型，强调其城市组织框架角色。

### 主要思想流派

新陈代谢派（Metabolism，日本，1960s）
- 将城市比作生命有机体，强调新陈代谢与生长
- 代表人物：丹下健三、黑川纪章、菊竹清训、槇文彦
- 代表作：丹下健三《东京湾规划》（1960）

阿基格拉姆（Archigram，英国，1960s）
- 激进技术乌托邦主义，建筑视为消费品与机器
- 代表人物：Peter Cook、Ron Herron、Dennis Crompton
- 代表项目：《插入城市》Plug-In City（1964）、《行走城市》Walking City（1964）

情境主义国际
- Constant Nieuwenhuys《新巴比伦》New Babylon（1956-1974）
- 覆盖全球的巨构网络，供后工作时代游荡者自由创造空间

Yona Friedman 空间城市
- 《空间城市》Ville Spatiale：在现有城市上方架设高架框架
- 居民可自行配置空间，强调自主性与不确定性

### 代表性案例
- 东京湾规划 / 丹下健三 / 1960 / 海上高架城市框架
- 插入城市 / Archigram Peter Cook / 1964 / 可插拔模块单元
- 行走城市 / Archigram Ron Herron / 1964 / 移动式巨构机器
- 中银胶囊塔 / 黑川纪章 / 1972 / 可替换胶囊单元
- 新巴比伦 / Constant Nieuwenhuys / 1956-74 / 全球游荡者网络
- 空间城市 / Yona Friedman / 1958+ / 高架自组织框架

### 与垂直城市更新的关联
- 框架即城市：更新策略从单体建筑转向系统性框架，为黏菌算法网络提供结构支撑
- 插件式更新：允许局部替换而不破坏整体，契合渐进式城市修复逻辑
- 基础设施思维：将交通、结构、公共空间整合为一体化系统

## 2. 未来主义巨构 Futuristic Megastructure

### 当代案例
- NEOM The Line（沙特）：170km 线性城市巨构，当代最雄心勃勃的巨构项目
- BIG（Bjarke Ingels Group）：结合可持续性、混合功能与创新结构系统
- Zaha Hadid Architects：流动形态的大尺度城市综合体

### 核心议题
- 气候响应型巨构：将环境性能整合入结构系统
- 垂直城市综合体：在单一结构内叠加居住、商业、公共空间
- 数字化设计工具：参数化设计使复杂巨构形态成为可能

## 3. 垂直都市主义与高密度 Vertical Urbanism High Density

### 理论框架
垂直都市主义：城市向上生长而非向外蔓延，创造高密度混合功能环境。

### 亚洲城市案例
- 香港：高架步行网络连接建筑、交通枢纽与公共空间，形成复杂多层城市环境
- 新加坡：地下网络、高架连廊与裙楼平台创造复杂空间层级
- 东京：多层城市设计整合地铁、商业与居住

### 重庆特殊性
- 山地地形天然形成多层城市环境
- 建筑、道路、基础设施叠加于陡峭山坡
- 快速城市化产生中国最戏剧性的垂直城市景观
- 地形迫使多层开发，形成建筑与基础设施的复杂空间关系

### 理论家
- Kenneth Yeang：生物气候摩天楼理论，整合自然通风、空中花园、垂直绿化

## 4. 结构性虚空 Structural Voids Architecture

### 核心概念
建筑虚空的多重功能：
- 采光井：将自然光引入密集结构内部
- 通风：改善建筑内部空气流通
- 公共空间：在密集城市结构中创造公共领域
- 实与空的关系：虚空作为建筑意义的生成器

### 代表案例
- OMA CCTV 总部（北京）：环形结构在中心创造结构性虚空，挑战传统塔楼类型
- 当代高层建筑：越来越多地整合垂直虚空、空中花园与中庭，创造垂直公共领域

### 理论家
- Rem Koolhaas / OMA：将虚空作为功能性与空间性装置

## 5. 未来废墟美学 Architectural Ruins Futuristic

### 理论背景
- 废墟迷恋（Ruinenlust）：从皮拉内西蚀刻画到当代城市探索，废墟美学是建筑的持久主题
- 设计废墟：当代建筑师设计预期自身衰败与转化的结构
- 未来废墟：推测性建筑项目想象未来废墟，探索无常性、气候变化与城市转型

### 与城市更新的关联
- 工业废墟再生：废弃工业结构转化为文化空间、公园与混合功能开发
- 保留衰败美学同时创造新城市生活
- Lebbeus Woods：战争撕裂城市中的寄生结构，作为抵抗与再生的场所

## 6. 多层地面建筑 Multi-level Ground Architecture

### 核心概念
- 高架地面平面：在密集城市环境中创造多层公共空间与流线
- 剖面城市（Section City）：城市生活组织于多个垂直层级而非单一地面

### 案例
- 香港高架步行系统：世界最长室外有盖自动扶梯系统（中环至半山）
- 新加坡、明尼阿波利斯：广泛的高架步行网络
- 丹下健三东京湾规划：在东京湾上方架设高架巨构，创造新地面层

### 与重庆的关联
重庆山地地形天然形成多层地面，是"多层地面"概念的现实原型，也是垂直城市更新的天然实验场。

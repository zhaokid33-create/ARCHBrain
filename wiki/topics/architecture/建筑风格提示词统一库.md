## 0) 用途与约定（精简版）
- 本库用于“建筑场景风格提取 + 提示词生成 + 风格复用”。
- 词库默认作为助手内部资源，不主动展示全量词条；默认交付可直接投喂的成品提示词。
- 仅当明确要求“查看词库内容/标签清单”时，展示库本体。

## 1) 统一工作流（v1 + v1.1 + v12 融合）
1. 场景判定（先判定再写词）
   - A 风格收录（参考图入库）
   - B 套用风格（目标图 + 风格名）
   - C 草图/线稿 -> 效果图
   - D 现状照片 -> 设计还原/改造
   - E 局部编辑（材质/季节/天气）
   - F 实景/渲染 -> 分析图
2. 锚点优先级
   - 结构/透视/体量 > 材质 > 光影 > 氛围 > 装饰
3. 保真控制
   - 任何改造任务必须写明“保持不变项”：体量关系、透视、主轮廓、关键开孔
4. 双模式输出
   - render_mode：保结构，换材质/光色/氛围
   - lineart_mode：锁线稿，补材质与明暗逻辑
5. 三段式交付（强制）
   - 场景判定 + 假设
   - 可复制提示词（代码块）
   - 参数建议 + 负向约束

## 2) 参数与负向基线（nanobanana2）
- steps: 28-45
- guidance: 5.5-7.5
- img2img denoise:
  - 保结构: 0.28-0.45
  - 中等重塑: 0.45-0.62
- style weight: 0.55-0.80
- texture weight: 0.45-0.70
- seed: 固定用于可复现

负向词基线（CN）:
结构扭曲，透视错误，比例失衡，过饱和，过度锐化，脏噪点，文字水印，logo，重影，塑料感。

负向词基线（EN）:
structural distortion, wrong perspective, broken proportions, oversaturation, over-sharpening halos, dirty noise, watermark, logo, ghosting, plastic look.

## 3) 风格条目统一结构（schema）
- style_id / machine_name / human_name.zh / human_name.en
- aliases
- source
- visual_dna（构图/体量/材质/光影/色彩/成像/情绪）
- texture_profile（roughness/specular/anisotropy/grain/seam_density/weathering）
- mode_templates.render_mode
- mode_templates.lineart_mode
- mode_negative.render_mode
- mode_negative.lineart_mode
- params（nanobanana2）
- version / updated

## 4) 现有可用风格索引（已整合）
### style_arch_001
- 中文名：金属模型（原名：冷灰金属体块极简风）
- 英文名：Metallic Model（原名：Cool Gray Metallic Massing Minimalism）
- 核心：冷灰金属体块 + 柔和棚拍 + 方圆体量对比 + 门洞穿透
- 适用：概念模型展示、竞赛气质图、当代展陈图

### style_arch_002
- 中文名：模型投影（原名：网格阴影构筑体）
- 英文名：Model Projection（原名：Grid-Shadow Tectonic Study）
- 核心：高机位 + 网格纸 + 手工构筑 + 长硬阴影 + 排版化图纸语言
- 适用：学术展板、研究型分析图、建筑实验模型表达

### 水粉草地
- 类型：类手绘水粉（平涂+干刷）
- 核心：大色块组织 > 明度分层 > 少量颗粒叠色
- 注入层：色彩-材质-笔触映射（不替代结构层）
- 适用：非摄影写实的建筑叙事氛围图

## 5) 调用规范（给我俩日常使用）
- 收录风格 <图片/路径>
- 套用风格 <风格名> 渲染图
- 套用风格 <风格名> 线稿图
- 风格迁移 <源图> -> <目标图>
- 局部替换 <区域> <材质>

默认策略：
- 用户未说明模式时，先自动识别；不确定则按 B-render_mode 执行并显式写假设。

## 6) 故障回退（保留）
当参考图分析失败（unsupported format）:
1. 先验证文件格式/尺寸/模式
2. 重编码为标准 RGB JPG/PNG
3. 用重编码图重新提取风格
4. 再按三段式交付，注明使用回退文件

## 7) 维护规则
- 新风格：新增 style_arch_### 并补齐 schema。
- 小改词汇：v1.1 / v1.2
- 结构重写：v2
- 每次命名变更需保留“原名 -> 新名”映射，避免历史调用失效。
